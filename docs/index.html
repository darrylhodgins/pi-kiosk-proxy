Hello, World!

This is the example page for pi-kiosk-proxy. If you see it on your Raspberry Pi, the kiosk is proxying a remote page successfully.

Next Steps

  1. Edit /home/pi/pi-kiosk-proxy/nginx-config/kiosk: remove the GitHub Pages rewrite line and change proxy_pass to your own web server.
  2. If your app is not at the root of its website, configure its path in /home/pi/pi-kiosk-proxy/scripts/run.sh.
  3. Check and reload NGINX with sudo nginx -t && sudo systemctl reload nginx.
